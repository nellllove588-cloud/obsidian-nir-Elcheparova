## Тема исследования
"Номинация профессиональной и социальной деятельности женщин в современном испанском и английском языках: сопоставительное исследование"

## Назначение структуры папок
- **00_Inbox** - входящие заметки, быстрые идеи, неразобранное
- **01_Literature** - конспекты статей, книг и других источников
- **02_Notes** - постоянные заметки, связанные вики-ссылками
- **03_Projects** - описание текущего НИР и его этапов
- **04_Drafts** - черновики разделов и глав
- **05_Output** - итоговые тексты и планы публикаций
- **Templates** - шаблоны для новых заметок
- **Attachments** - изображения, схемы и вложения
